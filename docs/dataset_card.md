# Dataset Card

## Task

Detect whether an LLM-agent tool call is semantically aligned with the user prompt. Each sample contains a user prompt, a tool name, and a binary label.

## Schema

- `user_prompt`: public-masked user request text.
- `tool_call_text`: called tool name.
- `label`: `0` for Normal, `1` for Mismatch.
- `prompt_source_file`: source ToolBench JSON file for the prompt.
- `prompt_source_toolkit`: ToolBench toolkit associated with the prompt.
- `tool_source_file`: source ToolBench JSON file for the tool.
- `tool_source_toolkit`: ToolBench toolkit associated with the tool.
- `source_prompt_hash`: hash used for prompt-level group split.
- `normal_tool_call_text`: observed normal tool for the same prompt.
- `mismatch_sampling_type`: mismatch generation rule.

## Label Construction

Normal rows are observed successful ToolBench prompt-tool pairs. Mismatch rows are generated by pairing the same prompt with a different observed ToolBench tool while excluding all normal tools observed for that prompt. This makes label 1 a prompt-tool alignment mismatch rather than a tool-name blacklist.

## Public Processing

Email and URL spans in prompts are replaced with `[EMAIL]` and `[URL]`. Rows with demo, onboarding, UUID-like, or otherwise low-quality tool-name patterns were filtered during dataset construction.

## Caveat

The mismatch setting tests clear semantic misalignment between prompt and tool name. More subtle mismatches, such as opening an email versus deleting an email, should be evaluated in future work as a finer-grained extension.
